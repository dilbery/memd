    BRING YOUR CONTEXT WITH YOU

    Connect an agent

    One memory service. The same context on every machine.

    Quick start
    01

    Get an access token

    Ask your server administrator for a token, or use Administration → Access tokens → Issue token. Choose the owner, memory store and permissions, with a separate token for each machine.

    Keep the token private. New tokens are shown only once.

    Open token administration →
    02

    Onboard your machine

    Run this in a terminal on the machine you want to connect. The installer prompts for your token and configures the supported clients it finds.

    Requires bash, curl and Python 3. Existing client settings are preserved.

    Download or inspect the installer ↗
    03

    Check the connection

    Restart your agent to load its new connection, then ask it to recall a topic you’ve saved before.

    “Use memd to recall my backup setup.”

    You can also unlock the Memory index tab with the same token and test a search here.

    Open memory index →

    Included integrations

    • Claude CodeMCP + automatic recall hook
    • CodexMCP bridge configuration
    • Claude DesktopLocal stdio bridge
    • piMemory extension

    Other MCP clients can use the endpoint below with an Authorization: Bearer header.

    Manage access

    Administrators can inspect token names, owners, last use and expiry in the Administration tab. Revocation takes effect immediately.
